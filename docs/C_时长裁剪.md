#  音频批量裁剪工具 v8 

## 📌 核心功能
批量处理 MP3 音频文件，根据 Excel 表格中的曲目信息进行裁剪，并自动添加淡入淡出效果。



---

## ⚙️ 配置参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `EXCEL_FILE` | `舞曲排布_示例.xlsx` | Excel 数据源文件 |
| `SHEET_NAME` | `完整曲序` | 工作表名称 |
| `AUDIO_FOLDER` | `B_output_mp3` | 音频文件存放目录 |
| `OUTPUT_FOLDER` | `C_裁剪输出` | 处理结果输出目录 |
| `FFMPEG_PATH` | `ffmpeg` | FFmpeg 可执行文件路径 |
| `FADE_IN_DURATION` | `0.1` 秒 | 淡入时长 |
| `FADE_OUT_DURATION` | `5.0` 秒 | 淡出时长 |

---



## 🔧 核心函数

### 1. `shortcut_to_time_info(value)`
**功能**：将简写数字转换为总秒数和显示文本

| 输入 | 输出 |
|------|------|
| `1.5` | `(90, '1分30秒')` |
| `3.0` | `(180, '3分00秒')` |
| `1.8` | `(108, '1分48秒')` |

**处理逻辑**：
- 支持 `int`、`float`、`str` 类型输入
- 空值或无效值返回 `(None, None)`
- 计算公式：`总秒数 = 分钟数 × 60`

---



### 2. `find_audio_file(filename)`

**功能**：在音频文件夹中智能查找 MP3 文件

**匹配策略（按优先级）**：
1. **精确匹配**：文件名完全一致（含 `.mp3` 扩展名）
2. **忽略大小写匹配**：去除扩展名后比较
3. **包含匹配**：文件名包含搜索词或搜索词包含文件名

**返回值**：匹配文件的完整路径，未找到返回 `None`

---



### 3. `build_ffmpeg_command()`

**功能**：构建带淡入淡出的 FFmpeg 命令（主方法）

**核心滤镜链**：

[0:a]afade=t=in:st=0:d={fade_in},afade=t=out:st={duration - fade_out}:d={fade_out}[a]



**命令参数**：

- `-ss`：开始时间（放在 `-i` 前加速寻址）
- `-t`：裁剪时长
- `-filter_complex`：音频滤镜处理
- `-c:a libmp3lame`：MP3 编码器
- `-b:a 320k`：最高质量 VBR

---



### 4. `build_ffmpeg_command_alt()`

**功能**：备用方法，使用两个独立 `afade` 滤镜

**适用场景**：旧版本 FFmpeg 不兼容 `filter_complex` 时

**核心差异**：
- 使用 `-af` 替代 `-filter_complex`
- 淡入参数使用 `length` 而非 `d`
- 淡出参数使用 `start_time` 和 `duration`

## 📊 处理流程

### 阶段一：初始化

<pre>
┌─────────────────────────────────────┐
│ 1. 切换到脚本所在目录 │
│ 2. 创建输出文件夹 `C_裁剪输出` │
│ 3. 扫描音频文件夹 `B_output_mp3` │
│ 4. 统计 MP3 文件数量 │
└─────────────────────────────────────┘
</pre>


### 阶段二：读取 Excel

<pre>
┌─────────────────────────────────────┐
│ 1. 读取 `舞曲排布_示例.xlsx` │
│ 2. 自动检测列名映射： │
│ - 歌曲名 → 包含"歌曲名"的列 │
│ - 开始时间 → 包含"开始时间"的列 │
│ - 裁剪时长 → 包含"裁剪后时长"的列 │
│ 3. 未找到时按位置索引（第5/7/8列） │
│ 4. 显示前5行数据预览 │
└─────────────────────────────────────┘
</pre>


### 阶段三：批量处理（循环）

<pre>
┌──────────────────────────────────────────────────────┐
│ 对 Excel 每一行执行： │
│ │
│ 1. 获取歌曲名 → 调用 `find_audio_file()` 查找文件 │
│ │
│ 2. 解析裁剪时长： │
│ ├─ 有效值 → 裁剪处理 │
│ └─ 无效值 → 复制原文件（添加 "_原版" 后缀） │
│ │
│ 3. 解析开始时间： │
│ ├─ 数字 < 100 → 按分钟计算 │
│ ├─ 数字 ≥ 100 → 按秒计算 │
│ └─ "MM:SS" 格式 → 解析为秒 │
│ │
│ 4. 检查输出文件是否已存在（避免重复处理） │
│ │
│ 5. 执行 FFmpeg 命令： │
│ ├─ 主方法（filter_complex） │
│ └─ 失败时自动重试备用方法（afade） │
│ │
│ 6. 记录处理结果（成功/失败/复制/跳过） │
└──────────────────────────────────────────────────────┘
</pre>


### 阶段四：输出统计

<pre>
┌─────────────────────────────────────┐
│ 统计信息： │
│ ✅ 成功裁剪数 │
│ ❌ 失败数 │
│ 📋 复制原版数（无裁剪时长） │
│ 📁 输出目录路径 │
│ │
│ 文件列表： │
│ - 文件名 (大小 KB) │

</pre>



## 🎯 关键特性

### 智能功能
| 特性 | 说明 |
|------|------|
| **文件去重** | 跳过已存在的输出文件（> 1000 字节） |
| **自动重试** | FFmpeg 失败时自动切换备用命令 |
| **灵活匹配** | 支持精确/忽略大小写/包含三种匹配模式 |
| **空值处理** | 无裁剪时长自动复制原文件 |
| **列自动检测** | 支持中文列名和位置索引 |



### 音频质量

- 编码器：`libmp3lame`
- 比特率：`320kbps`（VBR 最高质量）
- 淡入淡出：开头 0.1s 淡入，结尾 5.0s 淡出

---



## ⚠️ 错误处理

| 错误场景 | 处理方式 |
|----------|----------|
| 音频文件夹不存在 | 显示警告，继续运行 |
| Excel 列未找到 | 使用位置索引（第5/7/8列） |
| 音频文件未找到 | 记录失败，继续处理下一行 |
| FFmpeg 执行失败 | 自动尝试备用命令 |
| 输出文件大小为 0 | 自动删除无效文件 |
| 文件复制失败 | 记录异常，继续处理 |

## 🚀 使用前置条件

1. **安装依赖**：

  ```bash
  pip install pandas openpyxl
  ```

  

2. **安装 FFmpeg**：
   
   - Windows: 下载并添加到 PATH
   
   - macOS: brew install ffmpeg
   
   - Linux: sudo apt install ffmpeg
   
     
   
3. **目录结构**：

```
脚本目录/
├── C_crop_audio.py
├── 舞曲排布_示例.xlsx
├── B_output_mp3/          # 存放原始 MP3
└── C_裁剪输出/             # 自动生成，存放结果
```
